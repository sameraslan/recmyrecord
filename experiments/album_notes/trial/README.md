# Album notes trial

The files of the trial reported in `../REPORT-trial.md` (how to run them is in its section 9).

`sources/`, `packs/` and `out/excerpt/` contain text from Wikipedia articles, available under CC BY-SA 4.0: each file names its article, language and revision. `out/` also holds the notes written from them, which are adaptations and so CC BY-SA 4.0 as well. The rest of this folder is the repository's own.

`nothing_study/` records facts that research agents found on the web for 30 albums, with the URL of each source. It quotes no source text.
