# Full audit of the Spotify links of the 4,081 existing albums

Made 2026-10-06. Sources: `data-pipeline/catalog/albums.csv`, `frontcreck/public/data/albums.json`, `data-pipeline/overrides.json` (worktree `feat/audio-10k`), and Spotify's public embed page for every id checked. Nothing in the repository was changed. The first pass (32 shared ids, 40-album sample) is in `report.md`; its results are included in the totals and lists here.

## Method

- For each of the 1,086 existing albums whose sheet `spotify_url` id differs from the site id (1,143 minus 17 shared-id albums and the 40 sampled), the embed page of both ids was read: album title, credited artist, track list, track artists, lengths, cover image id.
- Automatic first step: a pair passed as the same album only if the site id and the sheet id both matched the catalog row's title (edition suffixes ignored) and artist, and the two track lists overlapped by at least 30 %. Everything else became a candidate.
- Every candidate was then judged by hand from artist, title and tracks; the automatic rule decided no verdict of a candidate. The 890 pairs the rule passed were not looked at one by one.
- For the 515 existing albums with no sheet link (524 minus the 6 in shared ids and the 3 with no Spotify id on the site), the site id alone was compared with the album's own artist and title: automatic match, then every mismatch judged by hand. This check cannot see a wrong edition or a same-titled album by the same artist.
- Spotify gave no release year. Where a verdict needs one (same-titled albums, reissue titles, which recording), it is marked **partly inferred**.

Requests: 2896 in total over both passes, all to open.spotify.com, HTTP codes {'200': 2896}; no refusal (no 403 or 429). Pace: at most one request every 1.2 s. The cover downloads from i.scdn.co are counted separately at the end.

## Limits

- The 890 automatically passed pairs and the 441 automatically passed no-sheet albums rest on the rule above, not on a hand check.
- A wrong edition, or a same-titled album by the same artist, is invisible for the albums with no sheet link.
- I did not look at any cover image; the downloaded covers were only checked for format and size.
- `overrides.proposed.json` entries name image files that are in the scratch folder, not in the repository. The existing files in `data-pipeline/overrides/` are 96x96 baseline JPEGs (three are about 192 px); the downloads are Spotify's 300x300 JPEGs as requested. The pipeline squares every override image to 96 px (`images.py`, `ATLAS_SPRITE_PX`), so the larger size works unchanged.
