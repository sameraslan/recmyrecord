# cutout-r

**Idea.** The tile is the nebula (ember top left, gold right, teal below, deep blue left, laid out like the map) and the italic r is cut out of it in sky black. The only one of the three that is not a dark square, so it stands apart in a tab row.

**At 16 px.** Four soft colour areas and a heavy black r; the letter has the strongest silhouette of the set and the tile is equally visible on light and dark tab bars. The corners are dimmed slightly toward the sky colour so it does not look like a flat app-store gradient.

**Weaknesses.** At 16 and 32 px the gas is smooth gradients only, which is closer to "gradient app icon" than to the marbled gas; the swirl only appears in the 180 px icon, which uses `feTurbulence` (a displacement for the marbling and a faint dust layer). That 180 px icon should be shipped as a PNG render: librsvg clips the displaced layer at the canvas edge (an undisplaced copy underneath fills the gap), browsers do not, so the two differ slightly near the border. Bright and saturated; the least "quiet" option.

Files are generated by `../build.py`.
